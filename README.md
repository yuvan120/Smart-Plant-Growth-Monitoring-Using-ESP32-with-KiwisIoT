# 🌱 Smart Plant Growth Monitoring Using ESP32 with KiwisIoT

## 📌 About the Project

Smart Plant Growth Monitoring Using ESP32 with KiwisIoT is an IoT-based project designed to monitor plant growing conditions in real time.

Using the ESP32 microcontroller and connected sensors, this project monitors important environmental parameters such as soil moisture, temperature, humidity, and light intensity.

The collected sensor data is transmitted to the KiwisIoT platform, where users can visualize and monitor plant conditions through an online dashboard from anywhere.

This project helps improve plant care, supports smart gardening, and demonstrates how IoT technology can be used in modern agriculture.
